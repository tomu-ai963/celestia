# CELESTIA — 出生天球

出生の日時と場所から、その瞬間の空を3Dで再構成する天文ビューア。
占い的な解釈は持たず、**天体が実際にどこにいたか**だけを描く。

依存は three.js (r128, CDN) のみ。星野データ `data/stars.json` を fetch するため、
表示にはローカルHTTPサーバーが必要（下記「ローカル確認」参照）。

---

## 実装済み（プロトタイプ v0.1）

| 領域 | 内容 |
|---|---|
| 暦法 | グレゴリオ暦 → ユリウス日（`julianDay`）。タイムゾーンは出生地プリセットから固定オフセット |
| 惑星 | JPL近似軌道要素（1800–2050）＋ケプラー方程式のニュートン反復。ヘリオ座標から地球位置を引いて地心化 |
| 月 | 短縮ELP級数（黄経19項 / 黄緯9項 / 距離5項）。精度は黄経で概ね ±0.01° |
| 太陽 | 地球ヘリオベクトルの反転 |
| 感受点 | 月の平均交点、平均リリス（軌道遠地点）を平均要素から算出 |
| 座標変換 | 黄道直交座標 → three.js 座標は `(x, z, -y)` で統一 |
| 地平線 | GMST → 地方恒星時 → 天頂ベクトルを黄道座標に変換し、直交する大円を描画 |
| 星野 | HYG v4.1 実データ 8,920星（等級6.5以下）。ビルド時に黄道座標へ変換・JSON化（178KB / gzip 78KB） |
| 星座線 | Stellarium western skyculture の HIP ポリラインを HYG と照合して座標解決。黄道12星座はゴールドで強調、他76星座は暗く描画 |
| 歳差 | 星野・星座線・IAU境界・天の川を親グループにまとめ、黄道極まわりに `1.39697°×T` 回転（惑星計算は当日座標のまま） |
| 天の川 | 銀河座標系の向きだけ正確な手続き生成の装飾レイヤー（銀緯ガウス減衰・銀河中心側が明るい非対称）。**天文データではない** |
| 星座 | 均等30度のサインと、IAU境界（蛇遣座を含む）を歳差補正して重ね、ズレを可視化 |

### 設計上の前提

ホロスコープの「サイン」は黄道の均等30度分割であり、実在の星座の大きさとも位置とも一致しない。
歳差により J2000 から現在まで約24度ずれている。本アプリはこのズレを隠さず、
`実際の星座` トグルで両者を重ねて見せることを演出の中心に据えている。

## 開発

星野データの再生成とテスト（Node 18+ が必要。生成済み `data/stars.json` はコミットされているので通常は不要）:

```sh
npm run build   # HYG v4.1 と Stellarium western skyculture をダウンロードして
                # data/stars.json と data/constellations.json を生成（tools/.cache にキャッシュ）
npm test        # 座標変換の検証（4恒星 ±0.1°）とデータの形式・サイズ検査
```

### ローカル確認

`data/stars.json` を fetch するため **file:// で index.html を直接開くと星野が表示されない**。
リポジトリ直下でHTTPサーバーを立てて開く:

```sh
npm run serve                 # npx serve（http://localhost:8000）
# または
python -m http.server 8000    # http://localhost:8000
```

## 既知の制約

- 惑星の精度は 1800–2050 の範囲外で急速に劣化する（JPL近似要素の適用範囲）
- タイムゾーンは固定オフセットのため、夏時間期間の出生時刻は最大1時間ずれる
- IAU 星座境界は黄道上の交点のみを近似した13区分で、実際の多角形境界ではない
- 星野は fetch で読み込むため file:// では動作しない（ローカルHTTPサーバーが必要）
- 天の川は**装飾レイヤー**であり天文データではない。銀河座標系の向き（銀河北極・銀河中心の
  J2000 値）だけを正確に再現した手続き生成の点群で、HYG 実星野とは別物
- 星の色は B-V → 色温度（Ballesteros近似）→ 黒体色 の近似変換。ci 欠損の40星は
  カタログ平均値 0.63 で代替
- 歳差は天球固定レイヤー（星野・星座線・IAU境界・天の川）全体を黄道極まわりに
  `1.39697° × T` 回転させる近似で適用。恒星の固有運動・章動・極運動は反映しない
- 星座線は Stellarium western skyculture 由来の6点の HIP が HYG に見つからず、該当箇所で
  ポリラインを分割している（見た目にはほぼ影響しない）
- `data/` 配下は CC BY-SA の派生データでコード（MIT）と別ライセンス。
  帰属・変更内容は [data/ATTRIBUTION.md](data/ATTRIBUTION.md) を参照
